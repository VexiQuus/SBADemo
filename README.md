# ABC Company — Furniture Store Demo

A static e-commerce website demonstration for **a SBA project (ABC Company)**, a fictional furniture retailer. The site presents furniture products and provides example storefront pages and shopping interactions, including product previews, a shopping cart, promotional-code handling, and checkout messaging.

> **Project type:** Front-end website prototype  

## Features

- **Home page** — company introduction, image slideshow, product showcase, and contact section.
- **Product previews** — modal windows display additional product images.
- **Shopping cart page** — example cart with quantity controls, item removal, subtotal/total calculations, and a promotional-code field.
- **Promotion example** — the cart recognises the demo code and applies a fixed discount, subject to the cart's minimum-order check.
- **Account interface** — login and sign-up screens are provided as front-end examples.
- **Information pages** — FAQ, terms, sitemap, and a language directory.
- **Responsive navigation** — a collapsible navigation menu for smaller screens.

## Technology

- HTML5
- CSS3
- JavaScript
- jQuery 2.2.2 (used by the cart page)
- W3.CSS-based styling included in `style.css`
- Font Awesome icons and Google Fonts loaded from external CDNs
